# Suika Game - Evolution Size Edition 🍉

スイカゲーム風のブラウザパズルゲームです。フルーツを落として合体させ、進化させてハイスコアを目指しましょう！

## 🎮 遊び方

1.  **フルーツを落とす**: 画面をクリック（またはタップ）すると、その位置にフルーツが落ちます。
2.  **進化させる**: 同じ種類のフルーツ同士がぶつかると、合体して一段階大きなフルーツに進化します。
3.  **ゲームオーバー**: フルーツが積み上がり、上部の点線を超えてしまうとゲームオーバーです。

### 操作方法
*   **PC**: マウス移動で位置調整、クリックでドロップ。
*   **スマホ**: タップでドロップ。ジャイロセンサー（傾き）による重力操作も可能です（スタートボタンをダブルタップで有効化）。

## ✨ 特徴

*   **物理演算**: Matter.jsを使用したリアルな挙動。
*   **オンラインランキング**: Google Apps Script (GAS) とスプレッドシートを使用したランキング機能。
*   **レスポンシブ対応**: PCでもスマホでも快適に遊べます。
*   **かわいいデザイン**: ポップな配色と丸文字フォント（M PLUS Rounded 1c）を使用。
*   **設定**: BGMと効果音のON/OFF切り替えが可能。

## 🛠️ 技術スタック

*   HTML5 / CSS3
*   JavaScript (ES6+)
*   [Matter.js](https://brm.io/matter-js/) (2D物理エンジン)

## 🚀 セットアップ

このゲームは静的なWebページとして動作します。

1.  このリポジトリをクローンまたはダウンロードします。
2.  `index.html` をブラウザで開くだけで遊べます。

### ランキング機能の設定 (開発者向け)

ランキング機能を使用するには、Google Apps Script (GAS) のセットアップが必要です。

1.  Googleスプレッドシートを新規作成します。
2.  「拡張機能」 > 「Apps Script」を開きます。
3.  `doGet` と `doPost` 関数を含むスクリプトを記述し、デプロイします（ウェブアプリとして公開、アクセス権限は「全員」）。
4.  発行されたURLを `script.js` と `result.js` の `API_URL` 定数に設定してください。
